## Observations

- Wayfinder is the multi-session planning on-ramp for foggy work too large for one session.
- It plans decisions rather than implementation deliverables and merges back to the main flow at `to-spec`.
- Map = one issue; decision tickets are child issues; map is an index, not a store.
- Frontier = open, unblocked, unclaimed tickets; assignment acts as claim.
- Ticket types: grilling, prototype, research, task. Research is the one-ticket-per-session exception.
- `task` is the only type that does work, but only to unblock a decision.
- Important control weakness: the default 'plan, don't do' rule can be overridden in the map Notes, and those Notes are agent-authored, allowing the constrained actor to author its own exception.
- Docs acknowledge stale-map/waterfall risk, verbose grilling, weak parallel-session shared-context behavior, and ambiguity around revising prior decisions.
