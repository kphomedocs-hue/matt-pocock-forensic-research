## Observations
- UI prototypes default to three radically different variants, capped at five.
- Strong preference is to mount variants into an existing real page so actual app chrome/data/density constrain the decision.
- Variants are switched by `?variant=` and a bottom switcher with keyboard navigation.
- Switcher should be hidden in production builds.
- Losing variants and switcher are removed from main; the full prototype set is preserved on the throwaway evidence branch.
- Variants must differ structurally, not cosmetically.
